Quant Formula Book

Every formula that matters for CAT QA, organised by topic. Revise one topic per sitting; re-derive each formula once so it sticks.

Percentages
  • x% of N = N × x⁄100
  • Successive change of a% then b%: a + b + ab⁄100 % (use signs; +20% then −20% ⇒ −4%)
  • If A is r% more than B, B is 100r⁄(100+r) % less than A
  • Price up r%, consumption must fall 100r⁄(100+r) % to keep expenditure same
  • Multiplying-factor thinking: +25% ⇒ ×5/4, −20% ⇒ ×4/5. Memorise fraction ↔ percent: 1/6 = 16.67%, 1/7 = 14.28%, 1/8 = 12.5%, 1/9 = 11.11%, 1/11 = 9.09%, 1/12 = 8.33%, 1/13 = 7.69%
Profit, Loss & Discount
  • Profit% = (SP − CP)⁄CP × 100; SP = CP × (1 + P%⁄100)
  • Markup m% then discount d%: Profit% = m − d − md⁄100
  • Two items sold at same SP, one +x% and one −x%: overall loss of x²⁄100 %
  • False weight: Profit% = (True − False)⁄False × 100
  • Successive discounts a%, b%: single discount = a + b − ab⁄100 %
Simple & Compound Interest
  • SI = PRT⁄100 · CI Amount = P(1 + r⁄100)ᵗ
  • Difference CI − SI for 2 years = P(r⁄100)²; for 3 years = P(r⁄100)²(3 + r⁄100)
  • Half-yearly compounding: rate → r/2, periods → 2t. Quarterly: r/4 and 4t
  • Rule of 72: money doubles in ≈ 72⁄r years
  • Instalments (CI): each instalment X satisfies P = Σ X⁄(1+r/100)ᵏ
Ratio, Proportion, Mixtures & Alligation
  • a : b = ka : kb; combine a:b and b:c by making b equal
  • Alligation: (cheap qty)⁄(dear qty) = (dear price − mean)⁄(mean − cheap price)
  • Repeated replacement: after n operations, milk left = V(1 − x⁄V)ⁿ (x drawn each time from volume V)
  • Partnership: profits split in ratio of (capital × time)
  • If a/b = c/d then (a+b)/(a−b) = (c+d)/(c−d) (componendo–dividendo)
Averages
  • Average = Sum ⁄ Count; a new member changes average by (member − old avg)/(n+1)
  • Weighted average: (n₁x₁ + n₂x₂)⁄(n₁ + n₂)
  • Average of first n naturals = (n+1)⁄2; of consecutive numbers = middle term
  • If average of a group increases by k when a person of weight w is replaced by W: W = w + nk
Time, Speed & Distance
  • km/h → m/s: × 5⁄18 · m/s → km/h: × 18⁄5
  • Equal distances at speeds a and b: average speed = 2ab⁄(a+b) (harmonic mean)
  • Trains: crossing a pole → distance = train length; crossing a platform → train + platform length. Opposite directions → add speeds; same direction → subtract
  • Boats: downstream = b + s, upstream = b − s; b = (D + U)⁄2, s = (D − U)⁄2
  • Circular tracks (same start): first meeting in L⁄(relative speed); meeting at start in LCM of lap times
  • Races: A beats B by x m in a race of L ⇒ speeds ratio L : (L − x)
Time & Work / Pipes
  • Rates add: A in a days, B in b days ⇒ together ab⁄(a+b) days
  • LCM method: take work = LCM of days, convert to units/day — fastest in the exam
  • M men, D days, H hrs for work W: M₁D₁H₁⁄W₁ = M₂D₂H₂⁄W₂
  • Efficiency ∝ 1/time. A is twice as efficient as B ⇒ A takes half the time
  • Inlet fills in a hrs, outlet empties in b hrs: net rate = 1/a − 1/b
Number System
  • HCF × LCM = product of two numbers
  • N = p^a · q^b · r^c ⇒ number of factors = (a+1)(b+1)(c+1); sum of factors = Π (pᵃ⁺¹−1)/(p−1)
  • Trailing zeroes of n! = ⌊n/5⌋ + ⌊n/25⌋ + ⌊n/125⌋ + …
  • Unit digits cycle with period 1, 2 or 4 — reduce the exponent mod 4
  • Remainders: (a×b) mod m = (a mod m × b mod m) mod m. Fermat: a^(p−1) ≡ 1 (mod p) if gcd(a,p)=1
  • Euler: a^φ(n) ≡ 1 (mod n); φ(n) = n·Π(1 − 1/p)
  • Divisibility: 3/9 → digit sum; 4 → last 2 digits; 8 → last 3; 11 → alternating digit sum; 7/13 → blocks of 3 alternating
  • Sums: Σn = n(n+1)/2 · Σn² = n(n+1)(2n+1)/6 · Σn³ = [n(n+1)/2]²
Algebra — Quadratics, Identities & Inequalities
  • ax² + bx + c = 0: sum of roots = −b/a, product = c/a; roots = (−b ± √(b²−4ac))⁄2a
  • Nature of roots: D > 0 real distinct, D = 0 equal, D < 0 complex
  • a³ + b³ = (a+b)(a² − ab + b²); a³ + b³ + c³ − 3abc = (a+b+c)(a²+b²+c²−ab−bc−ca)
  • AM ≥ GM ≥ HM (equality when all equal). For fixed sum, product is max when parts are equal; for fixed product, sum is min when equal
  • |x − a| < r ⟺ a − r < x < a + r. (x−α)(x−β) < 0 ⟺ α < x < β
  • Max/min of ax² + bx + c at x = −b/2a, value = c − b²/4a
Progressions & Logarithms
  • AP: Tₙ = a + (n−1)d, Sₙ = n⁄2 [2a + (n−1)d]
  • GP: Tₙ = arⁿ⁻¹, Sₙ = a(rⁿ−1)⁄(r−1), S∞ = a⁄(1−r) for |r|<1
  • AM of a,b = (a+b)/2; GM = √(ab); HM = 2ab/(a+b); GM² = AM × HM
  • log(ab) = log a + log b · log(a/b) = log a − log b · log aⁿ = n log a
  • Base change: log_b a = log a ⁄ log b; log_b a × log_a b = 1
  • a^(log_a x) = x; log_a 1 = 0; log values: log 2 ≈ 0.301, log 3 ≈ 0.477
Geometry — Triangles & Circles
  • Triangle area: ½ × base × height = √(s(s−a)(s−b)(s−c)) = ½ ab sin C = rs = abc/4R
  • Pythagorean triplets to memorise: (3,4,5), (5,12,13), (7,24,25), (8,15,17), (9,40,41), (20,21,29)
  • Similar triangles: sides ratio k ⇒ areas ratio k²; volumes of similar solids ⇒ k³
  • Angle bisector divides opposite side in ratio of adjacent sides. Apollonius: AB² + AC² = 2(AD² + BD²) for median AD
  • Equilateral (side a): area = √3⁄4 a², height = √3/2 a, R = a/√3, r = a/(2√3)
  • Circle: angle in semicircle = 90°; angle at centre = 2 × angle at circumference; opposite angles of cyclic quadrilateral sum to 180°
  • Tangent ⊥ radius; equal tangents from an external point; PA × PB = PT² (power of a point)
  • Chord: perpendicular from centre bisects it; d² + (c/2)² = r²
  • Regular polygon (n sides): each interior angle = (n−2)×180⁄n; exterior = 360/n; diagonals = n(n−3)/2
Coordinate Geometry
  • Distance = √((x₂−x₁)² + (y₂−y₁)²); section formula: ((mx₂+nx₁)/(m+n), (my₂+ny₁)/(m+n))
  • Slope m = (y₂−y₁)/(x₂−x₁); parallel ⇒ equal slopes; perpendicular ⇒ m₁m₂ = −1
  • Line: y = mx + c; ax + by + c = 0 has slope −a/b
  • Distance of (x₁,y₁) from ax+by+c=0: |ax₁+by₁+c| ⁄ √(a²+b²)
  • Triangle area with vertices: ½ |x₁(y₂−y₃) + x₂(y₃−y₁) + x₃(y₁−y₂)|
Mensuration
  • Cuboid: V = lbh, TSA = 2(lb+bh+lh), diagonal = √(l²+b²+h²). Cube: V = a³, TSA = 6a², diagonal = a√3
  • Cylinder: V = πr²h, CSA = 2πrh, TSA = 2πr(r+h)
  • Cone: V = ⅓πr²h, slant l = √(r²+h²), CSA = πrl, TSA = πr(l+r)
  • Sphere: V = 4⁄3 πr³, SA = 4πr². Hemisphere: V = ⅔πr³, TSA = 3πr²
  • Sector (angle θ): area = θ/360 × πr², arc = θ/360 × 2πr
  • Melting/recasting: volume is conserved — equate volumes
Modern Math — P&C, Probability, Sets, Binomial
  • nPr = n!⁄(n−r)! · nCr = n!⁄(r!(n−r)!); nCr = nC(n−r); nC0+nC1+…+nCn = 2ⁿ
  • Arrangements with repeats: n!/(p!·q!·…). Circular arrangements: (n−1)!; necklace: (n−1)!/2
  • k people together: glue them — (n−k+1)! × k!. No two together: arrange others, insert in gaps
  • Distribution: identical items into r distinct boxes = C(n+r−1, r−1)
  • Derangements: D(n) = n!(1 − 1/1! + 1/2! − …); D(4)=9, D(5)=44
  • P(A∪B) = P(A) + P(B) − P(A∩B); independent: P(A∩B) = P(A)P(B); P(A|B) = P(A∩B)/P(B)
  • Sets: |A∪B∪C| = Σ|A| − Σ|pairwise| + |A∩B∩C|; exactly-one/exactly-two counting via Venn regions
  • Binomial: (1+x)ⁿ term k+1 = C(n,k)xᵏ; greatest coefficient near middle
